Cypher 25 is the Neo4j Cypher version aligned with GQL, and it is relate's target. Where an openCypher proposal, Cypher 5 and Cypher 25 disagree, relate does what Cypher 25 does. It is the only version relate runs. A `CYPHER 25` prefix is accepted and changes nothing; any other version number, `CYPHER 5` included, fails with `UnsupportedCypherVersion`.

Each :term[namespace]{id=namespace} records a default language, and `SHOW DATABASES` reports it as `defaultLanguage`: `CYPHER 25`. `ALTER DATABASE <name> SET DEFAULT LANGUAGE` accepts `CYPHER 25` and refuses any other version.

```cypher
CYPHER 25 MATCH (p:Person) LET years = 2026 - p.since FILTER years >= 3 RETURN p.name AS name
```

Syntax that Neo4j has accepted but not settled is not part of the default: it is a :term[preview feature]{id=preview-feature}.
